Machine Learning is a subset of artificial intelligence that enables systems to learn patterns from data and make predictions or decisions. Supervised learning uses labeled data and includes classification and regression. Unsupervised learning uses unlabeled data and includes clustering. K-Means is a common clustering algorithm. Overfitting occurs when a model performs very well on training data but poorly on unseen data. A test dataset is used to estimate how well a trained model generalizes to unseen examples. Feature scaling is important for many distance-based algorithms because features with larger numerical ranges can dominate distance calculations. Cross-validation helps estimate model performance by repeatedly splitting available data into training and validation portions.
